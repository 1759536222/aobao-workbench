# 澳澳工作台 v4 — 牛油果绿风格 🥑

一个纯前端的个人生活管理工作台，**牛油果绿**自然清新色系，单 HTML 文件 + localStorage，数据不上传任何服务器。部署到 GitHub Pages 后，手机加到主屏幕就能当 App 用。

## 功能模块（11个，可开关可重命名）

| 模块 | 说明 |
|------|------|
| 🏠 **首页** | 每日一句 + 4个核心数据卡 + 今日概览 + 今日提醒 |
| 📝 **计划** | 每日待办清单+进度条 |
| 🎯 **目标** | 体重/存款目标+目标清单 |
| 📅 **重要日期** | 生日/纪念日/节日倒计时 |
| 💪 **健身** | 运动记录+体重趋势图 |
| 💧 **喝水计划** | 每日喝水打卡+杯子可视化+7天图表 |
| 💸 **日常支出** | 记账+预算+分类饼图 |
| 🌅 **早起** | 早起打卡+连续天数+7天图表 |
| 🌙 **睡觉** | 睡眠记录+质量评分+7天图表 |
| ⏰ **倒计时** | 考试/旅行倒计时 |
| 🌷 **经期** | 经期记录+日历预测 |
| ⚙️ **设置** | 模块管理+目标+AI配置+数据管理 |

## 设计风格

**牛油果绿色系** — 自然清新、护眼舒适：
- 主色：牛油果绿 `#7CB342`
- 深色：`#558b2f` / `#33691e`
- 浅色：`#9ccc65` / `#aed581` / `#c5e1a5` / `#dcedc8`
- 背景色：`#f1f8e9`（淡绿底）
- 圆角大卡片 + 绿色装饰条 + 渐变
- 自动适配深色模式

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `aobao-workbench`）
2. 把所有文件上传到根目录
3. Settings → Pages → Deploy from branch (main, /root)
4. 等1-2分钟访问 `https://你的用户名.github.io/aobao-workbench/`

## 手机加主屏幕

### iOS Safari
1. Safari 打开网址
2. 分享按钮 → 添加到主屏幕

### Android Chrome
1. Chrome 打开
2. 菜单 → 添加到主屏幕
